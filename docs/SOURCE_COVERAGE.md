# Source Coverage v1

## IMPLEMENTED

The private dossier, JSON/HTML report and Windows summary expose per-entity coverage for PHONE, EMAIL, USERNAME, DOMAIN, COMPANY and DOCUMENT: eligible, enabled, executed, blocked, unknown and successful sources, verified evidence references and independent groups. The compact GUI line reports executed/enabled sources, independent evidence, discovered entities, useful pivots and blocked/unavailable sources.

`SourceDiversityScore` measures independent source classes/domains plus first-party/archive and technical/textual mix. It is a coverage metric, not confidence or truth.

## NOT IMPLEMENTED

- Public telemetry or cross-user/provider analytics.
